📌 SECTION 1: PROBLEM KYA HAI? (Samajhlo pehle)
================================================================================

Ministry of Steel, Government of India — yeh log India ke East Coast ports 
(jaise Paradip, Visakhapatnam, Kamarajar, Haldia) par bahut bada maal mangwate
hain:
  - Iron Ore (loh) → Brazil aur Australia se
  - Coking Coal (koyala) → Australia aur South Africa se

Yeh sab samaan ship (cargo vessel) se aata hai. Ship book karne ko "Chartering"
bolte hain. Aur ship ka kiraya = "Freight Rate".

PROBLEM: Abhi Ministry ke officers roz manually market check karte hain, brokers
se baat karte hain, aur tab decide karte hain ki ship book karein ya nahi. Yeh
bahut slow hai aur kabhi kabhi bahut mehenga pad jaata hai kyunki:
  - Agar rate low tha aur unhone wait kiya → rate badh gaya → zyada paisa laga
  - Agar rate high tha aur unhone book kar liya → rate gir gaya → paisa waste

HUMARA SOLUTION: Ek AI/ML system banao jo PREDICT kare ki agle 7, 14, 30 din
mein freight rate kitna hoga. Isse Ministry ko pata chalega:
  - "Abhi book karo, rate badhne wala hai!" (CHARTER_NOW)
  - "Ruko, rate girne wala hai!" (WAIT)

Agar sirf $1/tonne bhi bacha liya → India imports 130 Million tonnes annually
→ $130 MILLION USD saved! Yahi hai IMPACT STATEMENT for SIH judges.

4.1 — XGBoost Model (Gradient Boosted Decision Trees)
========================================

File: src/models/xgboost_forecaster.py
Saved Model: models/xgboost_forecaster.json

KYA HAI YEH?
XGBoost ka full form hai "Extreme Gradient Boosting". Yeh bahut saare
chhote-chhote decision trees banata hai aur unhe ek ke baad ek train
karta hai. Har naya tree pichle tree ki galtiyon se seekhta hai.

SAMJHO AISE:
Sochlo tum 250 experts ko ek-ek karke bulate ho. Pehla expert apna
guess deta hai. Doosra expert pehle ki galti dekhta hai aur usse
sudharta hai. Teesra doosre ki galti sudharta hai... aur yeh process
250 baar hota hai. End mein sabka combined answer BAHUT accurate hota hai.

EK DECISION TREE EXAMPLE:
  AGAR iron_ore_price > 120 AUR bci_lag_7 > 2000:
      TAB freight_rate ≈ HIGH
  WARNA AGAR china_pmi < 50:
      TAB freight_rate ≈ LOW

XGBoost AISI 250 trees banata hai aur combine karta hai!

KEY HYPERPARAMETERS:
  → n_estimators=250    : 250 trees banaega
  → max_depth=6         : Har tree 6 level deep jaayega
  → learning_rate=0.03  : Dheere dheere seekhega (zyada stable)
  → subsample=0.85      : Har tree sirf 85% data use karega (overfitting roke)
  → colsample_bytree=0.85: Har tree sirf 85% features use karega

KYA KARTA HAI CODE MEIN:
1. prepare_data() → Data ko Train/Validation/Test mein todta hai (80/10/10)
2. train()        → Model train karta hai, validation pe early stopping lagata hai
3. predict()      → Naye data pe prediction deta hai
4. save()         → Trained model ko JSON file mein save karta hai

RESULTS:
  → Test MAE: 210.12 BCI points (average error)
  → Test MAPE: 13.76% (percentage error)
  → Directional Accuracy: 64.75% (rate upar jaayega ya neeche — 65% correct)

========================================
4.2 — BiLSTM Model (Bidirectional Long Short-Term Memory)
========================================

File: src/models/lstm_forecaster.py
Saved Model: models/bilstm_freight_net.pt

KYA HAI YEH?
LSTM ek special type ka Neural Network hai jo TIME SERIES data ke liye
banaya gaya hai. "Long Short-Term Memory" ka matlab hai — iske paas ek
"MEMORY" hoti hai jo purane patterns yaad rakhti hai.

SAMJHO AISE:
Sochlo tumhare paas 30 din ka newspaper hai shipping market ka. Tum
in 30 din ke patterns padh ke andaaza lagate ho ki 31st din kya hoga.
LSTM bilkul yahi karta hai — pichle 30 din ka data dekhta hai (lookback
window) aur agle din ka predict karta hai.

"Bi-Directional" ka matlab hai yeh DONO directions mein pattern dekhta
hai — aage se peeche AUR peeche se aage — isliye zyada accurate hai.

NETWORK ARCHITECTURE (Neural Network ki structure):

  INPUT: Pichle 30 din ka data (30 × 66 features = 1980 numbers)
    │
    ▼
  [LSTM Layer 1: 64 neurons, Bidirectional]
    → Dono directions mein patterns seekhta hai
    → Output: 128 values (64 forward + 64 backward)
    │
    ▼
  [Dropout: 20%]
    → Random 20% neurons OFF karta hai training mein
    → WHY? Overfitting rokne ke liye (model ratta na maare)
    │
    ▼
  [LSTM Layer 2: 64 neurons, Bidirectional]
    → Aur deeper patterns seekhta hai
    │
    ▼
  [Dropout: 20%]
    │
    ▼
  [Dense Layer: 32 neurons, ReLU activation]
    → Saare learned features ko combine karta hai
    │
    ▼
  [Output Layer: 1 neuron]
    → Final predicted BCI value

TRAINING PROCESS:
  → Optimizer: Adam (learning rate = 0.003)
  → Loss Function: MSE (Mean Squared Error)
  → Epochs: 35 (poore dataset pe 35 baar training)
  → Batch Size: 32 (ek baar mein 32 samples dekhta hai)
  → Gradient Clipping: max_norm=1.0 (training stable rakhe)

IMPORTANT CONCEPT — StandardScaler:
  Neural networks ko normalized data chahiye (values 0 ke aas paas).
  Agar BCI = 3000 aur Iron Ore = 120, toh network confuse ho jaayega.
  StandardScaler har feature ko mean=0, std=1 bana deta hai.
  Prediction ke baad INVERSE transform karke wapas original scale mein
  laate hain.

RESULTS:
  → Test MAE: 306.63 BCI points
  → Test MAPE: 20.41%
  → Directional Accuracy: 60.55%
  → XGBoost se thoda weak hai kyunki data chhota hai (LSTM ko bahut
    zyada data chahiye best performance ke liye)

========================================
4.3 — Ensemble Model (Sabko Mix Karo)
========================================

File: src/models/ensemble_forecaster.py

KYA HAI YEH?
Ensemble = Multiple models ki predictions ko COMBINE karo.
Jaise 3 doctors ki raay leke final decision lo — 3 models ki
predictions ka weighted average nikalo.

FORMULA:
  Final_Prediction = (0.55 × XGBoost) + (0.35 × BiLSTM) + (0.10 × Ridge)

  → XGBoost ko 55% weight diya kyunki yeh sabse accurate tha
  → BiLSTM ko 35% weight kyunki yeh sequential patterns pakadta hai
  → Ridge (simple linear model) ko 10% baseline stability ke liye

CONFIDENCE INTERVALS:
  → Sirf ek number predict karna kaafi nahi — UNCERTAINTY bhi batao
  → 95% Confidence Interval = "Hum 95% sure hain ki actual rate
    is range ke andar hoga"
  → Formula: Prediction ± (1.96 × Standard Deviation of residuals)

CHARTERING DECISION ENGINE:
  → AGAR 7-day forecast mein rate 4%+ BADHNE wala hai:
      → Signal: "CHARTER_NOW" 🟢 (Jaldi book karo warna mehenga padega!)
  → AGAR 7-day forecast mein rate 4%+ GIRNE wala hai:
      → Signal: "WAIT" 🔴 (Ruko, rate aur girega, sasta milega!)
  → WARNA:
      → Signal: "HOLD_NEUTRAL" ⚪ (Normal procurement chalu rakho)

RESULTS:
  → Test MAE: 237.73 BCI points
  → Test MAPE: 15.74%
  → Directional Accuracy: 59.63%

========================================
4.4 — SHAP Explainability Engine
========================================

File: src/models/explainability_shap.py

KYA HAI SHAP?
SHAP = SHapley Additive exPlanations. Yeh ek technique hai jo batati
hai ki MODEL NE YEH PREDICTION KYUN DIYA.

KYUN ZAROORI HAI?
Ministry ke officers AI pe tab hi trust karenge jab unhe samajh aaye
ki model kya soch raha hai. "Black box" pe koi trust nahi karega.

SHAP KAISE KAAM KARTA HAI:
Har ek feature ko ek SCORE milta hai (positive ya negative):
  → Positive Score = Yeh feature ne rate BADHAAYA
  → Negative Score = Yeh feature ne rate GHATAAYA

EXAMPLE OUTPUT:
  "7-Day BCI Forecast = 3000 points kyunki:"
  
  Base Market Level:        2500 (average historical rate)
  + Iron Ore Price High:    +300 (demand strong hai)
  + China PMI > 52:         +250 (Chinese factories full speed)
  - Fleet Size Increased:   -150 (zyada ships available = rate gira)
  + Port Congestion Paradip: +200 (ships stuck = kam available = rate badha)
  - Oil Price Dropped:      -100 (fuel sasta = operating cost kam)
  ─────────────────────────────────
  = Final Prediction:       3000

YEH MINISTRY KE LIYE INVALUABLE HAI! Officers dekh sakte hain:
"Aha, aaj rate isliye high hai kyunki iron ore ki demand badhi hai
aur Paradip port pe congestion hai."

GENERATED CHARTS:
1. reports/shap_summary.png    → Sabhi features ka importance ranking
2. reports/shap_latest_waterfall.png → Latest din ki prediction ka breakdown

📌 SECTION 8: EVALUATION METRICS (Model kitna accha hai?)
================================================================================

1. MAE (Mean Absolute Error)
   → Average mein prediction kitne points door thi actual se
   → Lower is better
   → Example: MAE = 210 matlab average 210 BCI points ki error

2. RMSE (Root Mean Squared Error)
   → MAE jaisa but badi errors ko ZYADA penalty deta hai
   → Lower is better
   → Agar kabhi bahut badi galti ho gayi, RMSE zyada badhega

3. MAPE (Mean Absolute Percentage Error)
   → Error ko PERCENTAGE mein batata hai (sabse intuitive)
   → MAPE = 13.76% matlab average 13.76% galti
   → Target: < 12% = Excellent, < 15% = Good, > 20% = Needs improvement

4. Directional Accuracy
   → Model ne kitni baar SAHI direction predict kiya?
   → "Rate badhega" bola aur sach mein badha = correct
   → "Rate girega" bola aur sach mein gira = correct
   → 64.75% = 100 mein se 65 baar sahi direction bataya
   → Yeh CHARTERING DECISIONS ke liye sabse important metric hai!
